# 笑傲江湖聊天室 - 系统说明文件

## 项目简介

笑傲江湖聊天室是一个基于武侠主题的多人在线聊天社交平台，融合了游戏、社交、经济系统等多种玩法。

**版本**: 2026 重构版  
**技术栈**: Vue 3 + Express + MySQL + Redis + Socket.IO

---

## 主要功能模块

### 1. 聊天系统
- 多房间聊天支持
- 私聊、公聊模式切换
- 丰富的表情系统（320+ 表情）
- 动作指令、特效消息
- 聊天历史记录

### 2. 游戏系统
- **门派系统**: 8 大门派，武学修炼
- **姻缘系统**: 结婚、生子、家庭
- **宠物系统**: 抓捕、培养、战斗
- **商城系统**: 道具购买、装备交易
- **经济系统**: 银两交易、市场监控

### 3. 娱乐功能
- 🎮 游戏中心（钓鱼、种田、挖矿、打猎）
- 🧪 配药炼制
- 🔮 求签问卜
- 🏆 排行榜系统
- 🌟 许愿池

### 4. 社交功能
- 好友系统
- 邮件系统
- 用户资料展示
- 在线用户列表

### 5. 管理后台
- 用户管理
- 内容审核
- 经济监控
- 安全防护
- 日志审计

## 快速启动

### Docker 部署（推荐）
```bash
# 启动所有服务
docker-compose up -d

# 初始化数据库
docker-compose exec backend node src/scripts/init-db.js

# 插入种子数据
docker-compose exec backend node src/scripts/seed.js
```

**访问地址**: http://localhost  
**管理员账号**: 站长 / admin123

## Socket.IO 事件

| 事件 | 方向 | 说明 |
|------|------|------|
| joinRoom | C→S | 加入聊天房间 |
| leaveRoom | C→S | 离开房间 |

| room:change | S→C | 房间切换通知 |
| user:join | S→C | 用户加入通知 |

## 常见问题

### 1. 音乐不播放？
- 浏览器阻止自动播放，需点击页面任意位置
- 检查音乐文件是否存在：`/assets/music/default_bgm.mp3`

### 2. 无法连接 Socket？
- 确认后端服务已启动（端口 3001）
- 检查 Vite 代理配置

### 3. 数据库连接失败？
- 检查 .env 配置（DB_HOST, DB_PASSWORD）
- Docker 环境使用 `mysql` 作为主机名
