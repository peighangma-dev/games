# 门派任务系统优化

## 1. 需求概述

完善门派任务玩法，提升用户参与度和游戏体验。

## 2. 当前问题

1. **一键完成**：任务无需过程，直接点击完成
2. **缺乏进度**：没有任务进度追踪
3. **刷新机制缺失**：日常任务完成后无法刷新
4. **分类混乱**：日常/支线任务混在一起
5. **缺少成就**：没有任务完成统计和成就
6. **奖励单一**：只有经验和银两

## 3. 功能需求

### 3.1 任务分类展示
- 【日常任务】每日可完成，刷新机制
- 【支线任务】一次性，永久记录
- 【师门任务】需要特定门派职位
- 【悬赏任务】高难度高奖励

### 3.2 任务进度追踪
- 显示当前进度（如：0/5）
- 进度类型：打猎、采集、训练等
- 自动/手动完成进度

### 3.3 任务刷新机制
- 日常任务每日自动刷新
- 可手动刷新（消耗银两）
- 刷新后重置完成状态

### 3.4 任务成就系统
- 记录完成任务总数
- 连续完成日常任务奖励
- 成就徽章和称号

### 3.5 UI 优化
- Tab 分类：日常 | 支线 | 师门 | 悬赏
- 任务难度标识颜色
- 进度条显示
- 任务追踪面板

## 4. 技术需求

- 添加 `user_quest_progress` 表追踪进度
- 添加 `quest_achievements` 表记录成就
- 每日零点自动刷新日常任务
- 添加任务完成统计 API

## 5. 验收标准

- [ ] 任务按类型分类展示
- [ ] 日常任务每日 0 点刷新
- [ ] 显示任务进度条
- [ ] 有任务成就统计
- [ ] UI 美观，操作流畅
