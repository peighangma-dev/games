# 游戏系统优化需求

## 1. 当前问题

1. **游戏数量少**：只有 3 个可玩游戏（21 点、骰子、钓鱼）
2. **功能失效**：猜大小、打猎、比山论剑未实现
3. **体验单一**：缺少动画效果、音效反馈
4. **界面简陋**：游戏卡片交互效果不足
5. **缺少激励**：成就系统不完善

## 2. 功能需求

### 2.1 新增可玩游戏
- ✅ 猜大小（High-Low）
- ✅ 打猎系统（Hunting）
- ✅ 比山论剑（Othello/黑白棋）

### 2.2 动画增强
- 游戏卡片 hover 粒子效果
- 胜利/失败动画特效
- 金币飞入效果
- 升级/成就烟花效果

### 2.3 音效系统
- 卡片翻牌音效
- 骰子滚动音效
- 胜利/失败音效
- 金币掉落音效

### 2.4 UI 优化
- 响应式游戏卡片
- 动态背景效果
- 加载动画
- 结算动画

### 2.5 成就系统
- 连胜记录追踪
- 总盈利统计
- 游戏次数统计
- 特殊成就徽章

## 3. 技术需求

- 使用 CSS3 动画和过渡
- Canvas 粒子系统
- Web Audio API 音效
- LocalStorage 本地存储
- 游戏状态管理优化

## 4. 验收标准

- [ ] 6 个游戏全部可玩
- [ ] 每个游戏有独特动画
- [ ] 音效开关功能
- [ ] 移动端适配
- [ ] 性能流畅（60fps）
