## 🔴 严重问题（必须修复）

### 1. 缺失的控制器文件
**位置**: `backend/src/routes/shop.js`  
**问题**: 路由引用 `../controllers/item` 但文件命名不规范  
**风险**: 运行时错误，功能失效  
**建议**: 统一命名规范，创建 `shop.js` 控制器或重命名 `item.js`

### 2. 数据库重复索引
**位置**: `users` 表  
**问题**: 
- `idx_all_value` 和 `idx_total_exp` 都在 `total_exp` 字段上
- `idx_month_value` 和 `idx_monthly_exp` 都在 `monthly_exp` 字段上
**影响**: 写入性能下降，存储空间浪费  
**修复**:
```sql
ALTER TABLE users DROP INDEX idx_all_value;
ALTER TABLE users DROP INDEX idx_month_value;
```

### 3. Socket 连接稳定性问题
**位置**: `frontend/src/views/Chat.vue`  
**问题**: 缺少断线重连机制  
**风险**: 用户长时间离线后无法恢复聊天  
**修复**: 添加自动重连逻辑和重连提示

## 🟡 警告问题（建议修复）

### 1. 过多的 console 日志
**统计**: 后端 309 处 console 调用  
**风险**: 生产环境性能影响，日志泄露  
**建议**: 
```javascript
// 使用 Winston 或其他日志库替换
logger.info/error/debug() 替代 console.log/error()
```

### 2. 不统一的响应格式
**位置**: 多个控制器  
**问题**: 部分响应缺少 `success` 字段  
**示例**:
```javascript
// ❌ 不规范
res.json({ data: [...] })

// ✅ 规范
res.json({ success: true, data: [...] })
```

### 3. SELECT * 查询过多
**统计**: 168 处 SELECT *  
**影响**: 
- 网络传输浪费
- 内存占用增加
- 数据库性能下降  
**建议**: 只查询需要的字段

### 4. 缺少请求频率限制
**位置**: 登录、注册、聊天接口  
**风险**: DDoS 攻击，暴力破解  
**建议**: 添加 rate limiting 中间件

### 5. API 缺少输入验证
**位置**: 多个 POST 接口  
**风险**: 恶意数据提交  
**建议**: 使用 Joi 或 express-validator 进行验证

### 6. 前端 localStorage 敏感数据
**位置**: `src/utils/api.js`  
**风险**: Token 明文存储，XSS 攻击可窃取  
**建议**: 
- 使用 httpOnly cookie
- 添加 token 刷新机制

### 7. 缺失错误边界处理
**位置**: 多个 Vue 组件  
**风险**: 单组件错误导致整个应用崩溃  
**建议**: 添加全局错误边界组件

### 8. 数据库连接池未配置
**位置**: `backend/src/utils/db.js`  
**风险**: 高并发时连接耗尽  
**建议**:
```javascript
createPool({
  connectionLimit: 20,
  queueLimit: 100
})
```

### 9. 静态资源缺少 CDN
**位置**: 前端静态资源  
**影响**: 首屏加载慢  
**建议**: 配置 CDN 加速

### 10. 缺少健康检查端点
**问题**: `/api/health` 返回 404  
**影响**: 无法进行服务监控  
**修复**: 添加健康检查路由

### 11. 环境变量硬编码
**位置**: 多处代码  
**风险**: 配置泄露，部署困难  
**建议**: 统一使用 process.env

### 12. 前端组件过大
**位置**: `Sect.vue`, `Games.vue` (800+ 行)  
**影响**: 难以维护，加载慢  
**建议**: 拆分为子组件
