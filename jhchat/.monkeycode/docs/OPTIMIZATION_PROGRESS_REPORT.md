## 💡 技术亮点

### 1. 动画性能优化
- 使用 `transform` 和 `opacity` 实现动画（GPU 加速）
- 避免 `left/top/width/height` 触发重排
- 关键动画使用 `will-change` 提示浏览器

### 2. 动画时长规范
- 入场动画：0.3-0.5s
- 反馈动画：0.5-0.8s
- 庆祝动画：1.5-2s
- 循环动画：1-3s/循环

### 3. 缓动函数选择
- 弹性效果：`cubic-bezier(0.34, 1.56, 0.64, 1)`
- 平滑过渡：`ease-in-out`
- 快速响应：`ease-out`

### 4. 古风配色现代化
- 保留 ASP 经典配色的同时，扩展现代配色层次
- 使用 CSS 变量实现主题化
- 提供渐变、阴影、圆角等完整设计系统

## 🔧 问题与解决

### 问题 1: 卡牌飞入动画方向
**现象**: 所有卡牌从同一方向飞入，缺乏真实感  
**解决**: 为每张牌计算不同的飞入角度和延迟

### 问题 2: 骰子 3D 效果
**现象**: 骰子滚动看起来像 2D 平面旋转  
**解决**: 使用 `transform-style: preserve-3d`和多轴旋转

### 问题 3: 古风配色太土
**现象**: 直接使用 ASP 原色显得过时  
**解决**: 保留核心色值，添加现代渐变和透明度层次
