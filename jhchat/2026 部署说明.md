## 第二步：安装运行环境

### 2.1 通过宝塔应用商店安装

登录宝塔面板后，进入 **应用商店**，依次安装以下应用：

#### 安装 Nginx

1. 在应用商店搜索 **Nginx**
2. 选择 **Nginx 1.28** 或更高版本（推荐 1.28.0）
3. 点击 **安装**
4. 安装完成后，进入 **设置** → **性能优化**，参考后续优化配置

#### 安装 MySQL

1. 在应用商店搜索 **MySQL**
2. 根据项目需求选择版本：
   - **MySQL 5.7**：兼容性好，占用资源较少
   - **MySQL 8.0**：性能更好，功能更丰富
3. 点击 **安装**
4. 安装完成后，记录 root 密码（或自行设置）

#### 安装 Redis

1. 在应用商店搜索 **Redis**
2. 选择 **Redis 6.0** 或更高版本
3. 点击 **安装**
4. 安装完成后启动 Redis 服务

#### 安装 Node.js 项目管理器

1. 在应用商店搜索 **Node.js**
2. 选择 **Node.js 项目管理器** 或 **Node.js 18**
3. 点击 **安装**
4. 安装完成后会显示 Node.js 版本（应该是 v18.x）

### 2.2 手动安装 Node.js 18（如果宝塔未提供）

如果宝塔应用商店中没有合适的 Node.js 版本，使用终端手动安装：

```bash
# 使用 NodeSource 源安装 Node.js 18
curl -fsSL https://deb.nodesource.com/setup_18.x | bash -
apt-get install -y nodejs  # Ubuntu/Debian

# 或
yum install -y nodejs  # CentOS

# 验证版本
node -v  # 应该显示 v18.x.x
npm -v
```

### 2.3 安装 PM2 进程管理器

通过 SSH 连接服务器，执行以下命令：

```bash
# 全局安装 PM2
npm install -g pm2

# 设置 PM2 开机自启
pm2 startup
# 按提示执行生成的命令（一般是 sudo env PATH=$PATH:... pm2 startup）

# 保存当前进程列表
pm2 save
```

### 2.4 安装完成后验证

在宝塔 **终端** 中执行：

```bash
# 检查 Nginx
nginx -v

# 检查 MySQL
mysql -V

# 检查 Redis
redis-cli ping  # 应返回 PONG

# 检查 Node.js
node -v
npm -v

# 检查 PM2
pm2 -v
```

1. 进入宝塔 **文件** → `/www/wwwroot/jhchat/`
2. 点击 **上传** 按钮
3. 选择本地打包的项目文件（建议上传 .zip 压缩包）
4. 上传完成后在线解压

如果代码在 Git 仓库中（如 GitHub、Gitee）：

1. 在宝塔 **终端** 中执行：

```bash
cd /www/wwwroot
git clone https://github.com/your-repo/games.git
cd games/jhchat
```

2. 如果需要指定分支：

```bash
git clone -b main --depth 1 https://github.com/your-repo/games.git
```

#### 方式三：使用 SFTP 工具

使用 FileZilla、WinSCP 等工具上传：

- **主机**: 服务器 IP
- **端口**: 22
- **用户名**: root（或你的 SSH 用户）
- **密码**: SSH 密码或密钥

上传到 `/www/wwwroot/jhchat/` 目录

## 第六步：配置后端服务

### 6.1 配置环境变量

在宝塔 **终端** 中执行：

```bash
cd /www/wwwroot/jhchat/backend

# 创建 .env 文件
cat > .env << 'EOF'
# 基础配置
NODE_ENV=production
PORT=3001

# 数据库配置
DB_HOST=localhost
DB_PORT=3306
DB_USER=jhchat
DB_PASSWORD=你的数据库密码
DB_NAME=jhchat

# Redis 配置
REDIS_HOST=localhost
REDIS_PORT=6379
# REDIS_PASSWORD= (如果设置了密码)

# JWT 配置（生产环境务必修改）
JWT_SECRET=生成一个随机字符串
JWT_EXPIRES_IN=7d

# 日志配置
LOG_LEVEL=info
LOG_DIR=/www/jhchat/logs

# 前端地址
FRONTEND_URL=http://你的域名.com

# 文件上传配置
UPLOAD_DIR=uploads/avatars
EOF

# 设置 .env 文件权限（仅所有者可读写）
chmod 600 .env
```

### 6.2 安装后端依赖

```bash
cd /www/wwwroot/jhchat/backend

# 安装依赖（仅生产环境依赖）
npm install --production

# 或安装所有依赖（包含开发依赖）
npm install

# 检查依赖安装情况
npm list --depth=0
```

### 6.3 创建 PM2 配置文件

```bash
cd /www/wwwroot/jhchat/backend

cat > ecosystem.config.js << 'EOF'
module.exports = {
  apps: [{
    name: 'jhchat-backend',
    script: 'src/server.js',
    instances: 1,
    exec_mode: 'cluster',
    env: {
      NODE_ENV: 'production',
      PORT: 3001
    },
    env_production: {
      NODE_ENV: 'production',
      PORT: 3001
    },
    error_file: '/www/jhchat/logs/pm2-error.log',
    out_file: '/www/jhchat/logs/pm2-out.log',
    log_file: '/www/jhchat/logs/pm2-combined.log',
    time: true,
    merge_logs: true,
    log_date_format: 'YYYY-MM-DD HH:mm:ss Z',
    max_memory_restart: '1G',
    watch: false,
    ignore_watch: ['node_modules', 'logs', 'uploads'],
    max_restarts: 10,
    min_uptime: '10s',
    restart_delay: 4000
  }]
};
EOF
```

### 6.4 启动后端服务

```bash
cd /www/wwwroot/jhchat/backend

# 使用 PM2 启动服务
pm2 start ecosystem.config.js --env production

# 查看状态
pm2 status

# 查看日志
pm2 logs jhchat-backend

# 保存 PM2 配置（开机自启）
pm2 save
```

### 6.5 测试后端服务

```bash

# 应该返回类似 {"status": "ok"} 的响应
```

## 第九步：配置反向代理

反向代理用于将 API 请求转发到后端服务，并支持 WebSocket 连接。

### 9.1 添加反向代理规则

在宝塔网站 **设置** → **反向代理** → **添加反向代理**：

#### API 接口代理

| 字段 | 值 |
|------|-----|
| 代理名称 | jhchat-api |
| 目标 URL | `http://127.0.0.1:3001` |
| 发送域名 | `$host` |
| 代理目录 | `/api/` |

#### Socket.IO 代理

再次添加反向代理：

| 字段 | 值 |
|------|-----|
| 代理名称 | jhchat-socket |
| 目标 URL | `http://127.0.0.1:3001` |
| 发送域名 | `$host` |
| 代理目录 | `/socket.io/` |

### 9.2 修改代理配置

添加反向代理后，点击 **修改配置文件**，添加 WebSocket 支持：

进入 **网站** → **设置** → **配置文件**，找到刚添加的反向代理配置，修改如下：

```nginx
# API 代理（注意：proxy_pass 末尾不要加斜杠 /）
location /api/ {
    proxy_pass http://127.0.0.1:3001;
    proxy_http_version 1.1;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $scheme;
    proxy_set_header X-Forwarded-Host $host;
    proxy_set_header X-Forwarded-Port $server_port;
    
    # WebSocket 支持（必需）
    proxy_set_header Upgrade $http_upgrade;
    proxy_set_header Connection "upgrade";
    
    # 超时设置
    proxy_connect_timeout 60s;
    proxy_send_timeout 60s;
    proxy_read_timeout 60s;
    
    # 关闭缓冲（实时通信）
    proxy_buffering off;
    proxy_cache off;
}

# Socket.IO WebSocket 代理（注意：proxy_pass 末尾不要加斜杠 /）
location /socket.io/ {
    proxy_pass http://127.0.0.1:3001;
    proxy_http_version 1.1;
    proxy_set_header Upgrade $http_upgrade;
    proxy_set_header Connection "upgrade";
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $scheme;
    proxy_set_header X-Forwarded-Host $host;
    proxy_set_header X-Forwarded-Port $server_port;
    
    # Socket.IO 需要这些头
    proxy_set_header Access-Control-Allow-Origin *;
    
    # WebSocket 超时设置（长连接）
    proxy_connect_timeout 60s;
    proxy_send_timeout 86400;
    proxy_read_timeout 86400;
    
    # 关闭缓冲（WebSocket 必需）
    proxy_buffering off;
    proxy_cache off;
}

# 文件上传代理
location /uploads/ {
    proxy_pass http://127.0.0.1:3001;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    
    # 文件上传大小限制
    client_max_body_size 20M;
}
```

⚠️ **重要提示**：

- `proxy_pass` 末尾**不要加斜杠** `/`，否则会导致 URL 路径被截断
  - 错误写法：`proxy_pass http://127.0.0.1:3001/api/;`
  - 正确写法：`proxy_pass http://127.0.0.1:3001;`
- WebSocket 支持必须添加 `Upgrade` 和 `Connection` 头
- Socket.IO 需要关闭缓冲（`proxy_buffering off`）

### 9.3 测试配置

```bash
# 测试 Nginx 配置语法
nginx -t

# 如果测试通过，重载配置
nginx -s reload

# 或

```

### 9.4 开启缓存优化（可选）

在网站 **配置文件** 中添加静态资源缓存：

```nginx
# 静态资源缓存（在 server 块中）
location ~* \.(jpg|jpeg|png|gif|ico|css|js|svg|woff|woff2|ttf|eot)$ {
    expires 30d;
    add_header Cache-Control "public, immutable";
}

location /assets/ {
    expires 30d;
    add_header Cache-Control "public, immutable";
}
```

### 9.5 开启 Gzip 压缩

在 **网站配置文件** 的 `server` 块中添加：

```nginx
# Gzip 压缩
gzip on;
gzip_vary on;
gzip_proxied any;
gzip_comp_level 6;
gzip_types text/plain text/css text/xml text/javascript application/json application/javascript application/xml+rss application/rss+xml font/truetype font/opentype application/vnd.ms-fontobject image/svg+xml;
gzip_min_length 256;
```

### 9.6 添加安全头部

在 **网站配置文件** 的 `server` 块中添加：

```nginx
# 安全头部
add_header X-Frame-Options "SAMEORIGIN" always;
add_header X-Content-Type-Options "nosniff" always;
add_header X-XSS-Protection "1; mode=block" always;
add_header Strict-Transport-Security "max-age=31536000; includeSubDomains" always;
```

## 第十步：配置 SSL 证书（推荐）

### 10.1 申请免费 Let's Encrypt 证书

在宝塔面板 **网站** → **设置** → **SSL**：

1. 选择 **Let's Encrypt** 标签
2. 确认域名正确
3. 输入邮箱（用于续期通知）
4. 勾选 **强制 HTTPS**（可选）
5. 点击 **申请**

### 10.2 申请成功后自动配置

申请成功后，宝塔会自动配置：

- SSL 证书路径
- HTTPS 重定向
- 证书自动续期任务

### 10.3 配置 HSTS（可选）

在 **网站配置文件** 中添加：

```nginx
# HSTS 头部（强制 HTTPS）
add_header Strict-Transport-Security "max-age=31536000; includeSubDomains; preload" always;
```

### 10.4 配置自动续期

宝塔会自动添加续期任务，可以在 **计划任务** 中查看：

- 任务类型：Shell 脚本

| 端口 | 协议 | 用途 | 源地址 |
|------|------|------|--------|
| 80 | TCP | HTTP | 0.0.0.0/0 |
| 443 | TCP | HTTPS | 0.0.0.0/0 |

**不要** 放行以下端口（仅限本地访问）：
- 3306 (MySQL)
- 6379 (Redis)
- 3001 (Node.js 后端)

```bash
cat > /usr/local/bin/jhchat-health.sh << 'EOF'
#!/bin/bash
# 江湖聊天室 - 健康检查脚本

LOG_FILE="/www/jhchat/logs/health.log"
BACKEND_URL="http://localhost:3001/api/ping"
FRONTEND_URL="http://localhost/"

log() {
    echo "$(date '+%Y-%m-%d %H:%M:%S') - $1" >> $LOG_FILE
}

# 检查后端
check_backend() {
    if curl -f -s $BACKEND_URL > /dev/null; then
        log "[OK] 后端服务正常"
        return 0
    else
        log "[ERROR] 后端服务异常"
        return 1
    fi
}

# 检查 Nginx
check_nginx() {
    if curl -f -s $FRONTEND_URL > /dev/null; then
        log "[OK] Nginx 服务正常"
        return 0
    else
        log "[ERROR] Nginx 服务异常"
        return 1
    fi
}

# 检查 MySQL
check_mysql() {
    if mysqladmin -u root -p'你的 MySQL 密码' ping > /dev/null 2>&1; then
        log "[OK] MySQL 服务正常"
        return 0
    else
        log "[ERROR] MySQL 服务异常"
        return 1
    fi
}

# 检查 Redis
check_redis() {
    if [ "$(redis-cli ping)" = "PONG" ]; then
        log "[OK] Redis 服务正常"
        return 0
    else
        log "[ERROR] Redis 服务异常"
        return 1
    fi
}

# 检查 PM2
check_pm2() {
    if pm2 status jhchat-backend | grep "online" > /dev/null; then
        log "[OK] PM2 服务正常"
        return 0
    else
        log "[ERROR] PM2 服务异常"
        return 1
    fi
}

# 执行检查
log "========== 开始健康检查 =========="
check_backend
check_nginx
check_mysql
check_redis
check_pm2
log "========== 健康检查完成 =========="
EOF

chmod +x /usr/local/bin/jhchat-health.sh
```

## 第十四步：备份策略

### 14.1 创建备份脚本

```bash
cat > /usr/local/bin/jhchat-backup.sh << 'EOF'
#!/bin/bash
# 江湖聊天室 - 自动备份脚本

BACKUP_DIR="/www/backup/jhchat"
DATE=$(date +%Y%m%d_%H%M%S)
MYSQL_USER="jhchat"
MYSQL_PASS="你的数据库密码"
MYSQL_DB="jhchat"

# 创建备份目录
mkdir -p $BACKUP_DIR/database
mkdir -p $BACKUP_DIR/code
mkdir -p $BACKUP_DIR/config

echo "开始备份 - $DATE"

# 1. 备份数据库
echo "备份数据库..."
mysqldump -u $MYSQL_USER -p$MYSQL_PASS \
    --single-transaction \
    --routines \
    --triggers \
    $MYSQL_DB | gzip > $BACKUP_DIR/database/jhchat_$DATE.sql.gz

# 2. 备份后端代码
echo "备份后端代码..."
tar -czf $BACKUP_DIR/code/backend_$DATE.tar.gz \
    -C /www/wwwroot/jhchat/backend .

# 3. 备份前端代码
echo "备份前端代码..."
tar -czf $BACKUP_DIR/code/frontend_$DATE.tar.gz \
    -C /www/wwwroot/jhchat/frontend .

# 4. 备份配置文件
echo "备份配置..."
cp /www/wwwroot/jhchat/backend/.env $BACKUP_DIR/config/env_$DATE
cp /www/jhchat/logs/env_$DATE 2>/dev/null || true

# 5. 删除 30 天前的备份
echo "清理旧备份..."
find $BACKUP_DIR -name "*.gz" -mtime +30 -delete
find $BACKUP_DIR -name "env_*" -mtime +30 -delete

echo "备份完成：$DATE"
echo "备份大小：$(du -sh $BACKUP_DIR | cut -f1)"
EOF

chmod +x /usr/local/bin/jhchat-backup.sh
```

```bash
#!/bin/bash
# 江湖聊天室 - 回滚脚本

BACKUP_DIR="/www/backup/jhchat"

# 选择最近的备份
LATEST_BACKUP=$(ls -t $BACKUP_DIR/code | grep backend | head -1)
LATEST_DB=$(ls -t $BACKUP_DIR/database | grep jhchat | head -1)

echo "准备回滚..."

rm -rf backend
tar -xzf $BACKUP_DIR/code/$LATEST_BACKUP -C backend/

# 回滚数据库
gunzip -c $BACKUP_DIR/database/$LATEST_DB | mysql -u jhchat -p'你的数据库密码' jhchat

# 重启服务
pm2 restart jhchat-backend
nginx -s reload

echo "回滚完成"
EOF

chmod +x /usr/local/bin/jhchat-rollback.sh
```

## 性能优化建议

### Nginx 性能优化

在宝塔 **Nginx 设置** → **性能优化** 中配置，或编辑 `nginx.conf`：

```nginx
# 工作进程
worker_processes auto;
worker_rlimit_nofile 65535;

events {
    use epoll;
    worker_connections 4096;
    multi_accept on;
}

http {
    # 基础优化
    sendfile on;
    tcp_nopush on;
    tcp_nodelay on;
    keepalive_timeout 65;
    types_hash_max_size 2048;
    
    # 连接优化
    keepalive_requests 100;
    reset_timedout_connection on;

    # 请求体缓冲
    client_body_buffer_size 10K;
    client_header_buffer_size 1k;
    client_max_body_size 20M;
    large_client_header_buffers 2 1k;

    # 打开文件缓存
    open_file_cache max=10000 inactive=30s;
    open_file_cache_valid 60s;
    open_file_cache_min_uses 2;

    # 代理缓冲
    proxy_buffer_size 4k;
    proxy_buffers 4 32k;
    proxy_busy_buffers_size 64k;
}
```

### MySQL 性能优化

在宝塔 **MySQL 设置** → **性能调整** 中配置，或编辑 `my.cnf`：

```ini
[mysqld]
# 基础配置
character-set-server = utf8mb4
collation-server = utf8mb4_unicode_ci

# 性能优化（根据服务器配置调整）
# 2 核 4GB 配置
innodb_buffer_pool_size = 2G
innodb_log_file_size = 256M
innodb_flush_log_at_trx_commit = 2
innodb_flush_method = O_DIRECT

# 连接数
max_connections = 200
thread_cache_size = 50

# 查询缓存（MySQL 5.7）
query_cache_type = 1
query_cache_size = 64M
query_cache_limit = 2M

# 日志
slow_query_log = 1
slow_query_log_file = /www/server/data/mysql/mysql-slow.log
long_query_time = 2
```
