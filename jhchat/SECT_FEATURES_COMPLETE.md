# 门派系统功能完善说明

## 📜 概述

参考原版 ASP 程序的门派玩法，完善了新版的门派系统功能，增加了更多互动性和管理功能。

---

## ✨ 新增功能

### 1. 掌门禅让 👑

掌门可以将掌门之位禅让给其他门派成员。

**功能特点：**
- 只有现任掌门可以禅让
- 禅让对象必须是本门派成员
- 禅让后原掌门自动成为长老
- 新掌门自动继位

**使用方法：**
1. 掌门在门派成员列表中点击某成员的"禅让"按钮
2. 确认禅让
3. 禅让成功后，对方成为新掌门，您成为长老

**API:**
```
POST /sects/abdicate
Body: { newLeader: "用户名" }
```

---

### 2. 招收弟子 📢

掌门和长老可以招收新弟子加入门派。

**功能特点：**
- 掌门和长老有招收权限
- 只能招收无门派的玩家
- 受门派性别限制约束
- 自动更新门派人数

**使用方法：**
1. 掌门/长老点击"招收弟子"按钮
2. 输入要招收的用户名
3. 确认招收

**API:**
```
POST /sects/recruit
Body: { username: "用户名" }
```

---

### 3. 开除弟子 ⚠️

掌门可以将违反门规的弟子逐出师门。

**功能特点：**
- 只有掌门可以开除弟子
- 不能开除掌门自己
- 被开除者自动成为无门派人士
- 自动更新门派人数

**使用方法：**
1. 掌门在成员列表中点击"开除"按钮
2. 确认开除

**API:**
```
POST /sects/expel
Body: { username: "用户名" }
```

---

### 4. 解散门派 💥

掌门可以解散整个门派。

**功能特点：**
- 只有掌门可以解散
- 六扇门（朝廷机构）不可解散
- 解散后所有成员自动除名
- 需要输入门派名称确认（防误操作）

**使用方法：**
1. 掌门点击"解散门派"按钮
2. 输入门派名称确认
3. 确认解散

**API:**
```
POST /sects/dissolve
Body: { name: "门派名称" }
```

## 🎯 门派等级体系

参考原版 ASP，门派内部有以下等级：

| 等级 | 权限 | 说明 |
|------|------|------|
| **掌门** | 全部权限 | 创建者或禅让继位 |
| **长老** | 招收弟子 | 原掌门禅让后成为长老 |
| **普通弟子** | 基础权限 | 普通成员 |

### 权限说明

| 操作 | 掌门 | 长老 | 普通弟子 |
|------|------|------|---------|
| 修改门派信息 | ✅ | ❌ | ❌ |
| 招收弟子 | ✅ | ✅ | ❌ |
| 开除弟子 | ✅ | ❌ | ❌ |
| 禅让掌门 | ✅ | ❌ | ❌ |
| 解散门派 | ✅ | ❌ | ❌ |
| 领取俸禄 | ✅ | ✅ | ✅ |
| 离开门派 | ✅ | ✅ | ✅ |

## 🏛️ 门派创建规则

### 创建条件

1. **等级要求:** 等级 ≥ 5
2. **银两要求:** 100 万两银子
3. **门派状态:** 当前无门派
4. **名称检查:** 不可使用"六扇门"（朝廷机构）

### 创建费用

- **费用：** 100 万两银子
- **扣除方式：** 创建时自动扣除
- **用途：** 门派建设资金

### 创建流程

1. 点击"创建门派"按钮
2. 填写门派信息：
   - 门派名称（必填）
   - 门派口号（可选）
   - 门派介绍（可选）
   - 门规（可选）
   - 性别限制（可选）
3. 确认创建
4. 自动成为掌门

---

## 🚪 加入门派规则

### 加入条件

1. **当前状态:** 无门派
2. **性别要求:** 符合门派性别限制
3. **特殊门派:** 六扇门需等级 10 以上（待实现）

### 加入方式

**方式一：主动申请**
1. 浏览门派列表
2. 选择心仪的门派
3. 点击"加入门派"
4. 自动加入

**方式二：被招收**
1. 掌门/长老发起招收
2. 系统自动执行
3. 成为普通弟子

## 💰 门派俸禄系统

### 俸禄计算

```
俸禄 = 等级 × 500 两
```

**示例：**
- 等级 1: 500 两
- 等级 5: 2,500 两
- 等级 10: 5,000 两
- 等级 50: 25,000 两

### 领取规则

- **领取时间:** 每日一次（0 点刷新）
- **领取条件:** 已加入门派
- **自动检查:** 系统自动判断是否可领取

### 领取方式

1. 进入门派页面
2. 查看俸禄信息
3. 点击"领取俸禄"
4. 银两自动到账

## 🔧 后端 API

### 新增接口

| 接口 | 方法 | 权限 | 说明 |
|------|------|------|------|
| `/sects/abdicate` | POST | 掌门 | 禅让掌门 |

| 错误 | HTTP 状态码 | 说明 |

## 📱 使用流程示例

### 场景一：创建并管理门派

```
1. 创建"逍遥派"（消耗 100 万两）
2. 成为掌门
3. 设置门派口号："笑傲江湖，逍遥自在"
4. 招收第一个弟子：令狐冲
5. 令狐冲表现好，升为长老
6. 想退隐江湖，禅让给令狐冲
7. 成为长老，享受清闲
```

### 场景二：接手掌门

```
1. 被现任掌门禅让
2. 成为新掌门
3. 修改门派信息
4. 招收新弟子
5. 开除违反门规的弟子
6. 带领门派发展壮大
```

### 场景三：解散门派

```
1. 门派成员都离开了
2. 决定解散门派
3. 点击"解散门派"
4. 输入门派名称确认
5. 门派解散，成为无门派人士
6. 可以重新创建或加入其他门派
```

## 🛡️ 安全机制

### 防误操作

1. **解散确认:** 必须输入门派名称
2. **禅让确认:** 二次确认弹窗
3. **权限验证:** 后端验证操作权限
4. **Token 验证:** 所有操作需认证

### 数据一致性

1. **事务处理:** 关键操作使用事务
2. **人数同步:** 自动更新成员数
3. **状态检查:** 操作前检查状态
4. **错误回滚:** 失败时回滚更改
