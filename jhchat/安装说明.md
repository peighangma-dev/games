# JHChat 安装说明

本文档提供两种安装方式：纯净 Linux 系统安装（Docker）和宝塔 Linux 面板安装。

## 系统要求

### 硬件要求
- CPU: 2 核心或更高
- 内存：2GB 或更高
- 硬盘：10GB 可用空间或更高
- 网络：稳定的互联网连接

### 软件要求
- 操作系统：Linux (Ubuntu 20.04+ / CentOS 7+)
- Docker 方式：Docker 和 Docker Compose
- 宝塔方式：宝塔面板 9.0+、MySQL 8.0+、Node.js 20+

## 方式一：纯净 Linux 系统安装（Docker 推荐）

### 第 1 步：安装 Docker 和 Docker Compose

```bash
# 安装 Docker
curl -fsSL https://get.docker.com -o get-docker.sh
sudo sh get-docker.sh

# 安装 Docker Compose
sudo curl -L "https://github.com/docker/compose/releases/latest/download/docker-compose-$(uname -s)-$(uname -m)" -o /usr/local/bin/docker-compose
sudo chmod +x /usr/local/bin/docker-compose

# 验证安装
docker --version
docker-compose --version
```

### 第 2 步：克隆项目代码

```bash
# 克隆仓库
git clone <仓库地址> jhchat
cd jhchat
```

### 第 3 步：配置环境变量

```bash
# 复制环境变量模板
cp backend/.env.example backend/.env

# 编辑配置文件（按需修改数据库密码等）
vim backend/.env
```

**关键配置项：**
```bash
# 数据库配置
DB_HOST=db
DB_PORT=3306
DB_USER=jhchat_user
DB_PASS=YourStrongPassword123!
DB_NAME=jhchat

# JWT 配置
JWT_SECRET=YourRandomSecretKeyHere

# 应用配置
NODE_ENV=production
PORT=3001
```

### 第 4 步：初始化数据库

```bash
# 启动所有服务
docker-compose up -d

# 等待数据库启动（约 30 秒）
sleep 30

# 执行数据库初始化脚本
docker-compose exec backend node src/scripts/init-db.js

# 插入初始数据
docker-compose exec backend node src/scripts/seed.js
```

### 第 5 步：验证服务

```bash
# 查看容器状态
docker-compose ps

# 查看后端日志
docker-compose logs backend

# 查看前端日志
docker-compose logs frontend
```

### 第 6 步：访问应用

打开浏览器访问：
- 前端：http://服务器 IP:5173
- 后端 API：http://服务器 IP:3001/api

**管理员账号：**
- 用户名：站长
- 密码：admin123

**重要提示：首次登录后请立即修改管理员密码！**

### 第 7 步：配置生产环境（可选）

#### 使用 Nginx 反向代理

```bash
# 安装 Nginx
sudo apt install nginx -y  # Ubuntu/Debian
# sudo yum install nginx -y  # CentOS

# 创建 Nginx 配置
sudo vim /etc/nginx/conf.d/jhchat.conf
```

**Nginx 配置示例：**
```nginx
server {
    listen 80;
    server_name your-domain.com;

    # 前端
    location / {
        proxy_pass http://localhost:5173;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_cache_bypass $http_upgrade;
    }

    # 后端 API
    location /api {
        proxy_pass http://localhost:3001;
        proxy_http_version 1.1;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header Host $http_host;
    }

    # WebSocket 支持
    location /socket.io {
        proxy_pass http://localhost:3001;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header Host $host;
    }
}
```

```bash
# 测试配置并重启 Nginx
sudo nginx -t
sudo systemctl restart nginx
```

#### 配置 HTTPS（使用 Let's Encrypt）

```bash
# 安装 Certbot
sudo apt install certbot python3-certbot-nginx -y

# 获取证书
sudo certbot --nginx -d your-domain.com

# 自动续期（已添加到 cron）
sudo certbot renew --dry-run
```

在云服务商控制台安全组中放行面板端口（默认 8888）：

- **腾讯云**：控制台 → 安全组 → 放行 8888 端口
- **华为云**：控制台 → 安全组 → 添加入站规则


在浏览器中打开：
```

```

## 宝塔面板常见问题

### Q1: 无法访问面板

**排查步骤：**

1. 检查安全组是否放行端口
2. 检查面板是否运行
```bash
bt restart
```
3. 获取最新访问地址
```bash
bt default
```
4. 查看错误日志
```bash
cat /www/server/panel/logs/error.log
```

### Q2: 面板提示 SSL 证书不受信任

**解决方法：**

1. 下载并安装宝塔根证书：
   - Windows：https://dg2.bt.cn/ssl/baota_root.pfx
   - macOS：https://dg2.bt.cn/ssl/mac.crt

2. 或添加浏览器例外安全访问

### Q3: 内存不足

**增加 Swap：**
```bash
dd if=/dev/zero of=/swap bs=1M count=2048
mkswap /swap
swapon /swap
echo '/swap swap swap defaults 0 0' >> /etc/fstab
```

### Q4: 软件安装失败

**解决方法：**

1. 更换软件源
2. 检查磁盘空间
```bash
df -h
```
3. 查看安装日志
```bash
tail -f /www/server/panel/logs/install.log
```

### Q5: PM2 进程异常

**解决方法：**

```bash
# 重启 PM2 进程
pm2 restart jhchat-backend

# 查看进程日志
pm2 logs jhchat-backend

# 删除并重新添加
pm2 delete jhchat-backend
pm2 start src/server.js --name jhchat-backend
```

## 常见问题

### Q1: 数据库连接失败

**问题：** 启动时提示 `ECONNREFUSED` 或 `Access denied`

**解决：**
```bash
# 检查 MySQL 是否运行
docker-compose ps  # Docker 方式
pm2 status  # 宝塔方式

# 验证数据库配置
cat backend/.env
```

### Q2: 前端页面空白

**问题：** 访问前端页面显示空白

**解决：**
1. 检查前端是否已构建
2. 检查 Nginx 配置文件根目录
3. 查看浏览器控制台错误信息
4. 确认 WebSocket 连接正常

### Q3: WebSocket 连接失败

**问题：** 登录后无法发送消息或聊天室不更新

**解决：**
1. 检查后端 PM2 进程是否正常
2. 验证 Nginx 的 WebSocket 配置
3. 检查防火墙是否开放端口
4. 查看后端日志：`pm2 logs jhchat-backend`

### Q4: 管理员无法登录

**问题：** 登录时提示密码错误

**解决：**
```bash
# 重置管理员密码
docker-compose exec backend node src/scripts/seed.js  # Docker 方式
cd backend && node src/scripts/seed.js  # 宝塔方式

# 确认账号信息
mysql -u jhchat_user -p -e "USE jhchat; SELECT username FROM users WHERE grade = 10;"
```

### Q5: 如何备份数据库？

**Docker 方式：**
```bash
# 备份
docker-compose exec db mysqldump -u root -pjhchat_root_pass jhchat > backup.sql

# 恢复
docker-compose exec -T db mysql -u root -pjhchat_root_pass jhchat < backup.sql
```

**宝塔方式：**
```bash
# 使用宝塔面板
# 数据库 → jhchat → 备份

# 或命令行
mysqldump -u jhchat_user -p jhchat > backup.sql
```
