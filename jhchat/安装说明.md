# JHChat 安装说明

本文档提供两种安装方式：纯净 Linux 系统安装（Docker）和宝塔 Linux 面板安装。

## 系统要求

### 硬件要求
- CPU: 2 核心或更高
- 内存：2GB 或更高
- 硬盘：10GB 可用空间或更高
- 网络：稳定的互联网连接

### 软件要求
- 操作系统：Linux (Ubuntu 20.04+ / CentOS 7+)
- Docker 方式：Docker 和 Docker Compose
- 宝塔方式：宝塔面板 9.0+、MySQL 8.0+、Node.js 20+

## 方式一：纯净 Linux 系统安装（Docker 推荐）

### 第 1 步：安装 Docker 和 Docker Compose

```bash
# 安装 Docker
curl -fsSL https://get.docker.com -o get-docker.sh
sudo sh get-docker.sh

# 安装 Docker Compose
sudo curl -L "https://github.com/docker/compose/releases/latest/download/docker-compose-$(uname -s)-$(uname -m)" -o /usr/local/bin/docker-compose
sudo chmod +x /usr/local/bin/docker-compose

# 验证安装
docker --version
docker-compose --version
```

### 第 2 步：克隆项目代码

```bash
# 克隆仓库
git clone <仓库地址> jhchat
cd jhchat
```

### 第 3 步：配置环境变量

```bash
# 复制环境变量模板
cp backend/.env.example backend/.env

# 编辑配置文件（按需修改数据库密码等）
vim backend/.env
```

**关键配置项：**
```bash
# 数据库配置
DB_HOST=db
DB_PORT=3306
DB_USER=jhchat_user
DB_PASS=YourStrongPassword123!
DB_NAME=jhchat

# JWT 配置
JWT_SECRET=YourRandomSecretKeyHere

# 应用配置
NODE_ENV=production
PORT=3001
```

### 第 4 步：初始化数据库

```bash
# 启动所有服务
docker-compose up -d

# 等待数据库启动（约 30 秒）
sleep 30

# 执行数据库初始化脚本
docker-compose exec backend node src/scripts/init-db.js

# 插入初始数据
docker-compose exec backend node src/scripts/seed.js
```

### 第 5 步：验证服务

```bash
# 查看容器状态
docker-compose ps

# 查看后端日志
docker-compose logs backend

# 查看前端日志
docker-compose logs frontend
```

### 第 6 步：访问应用

打开浏览器访问：
- 前端：http://服务器 IP:5173
- 后端 API：http://服务器 IP:3001/api

**管理员账号：**
- 用户名：站长
- 密码：admin123

**重要提示：首次登录后请立即修改管理员密码！**

### 第 7 步：配置生产环境（可选）

#### 使用 Nginx 反向代理

```bash
# 安装 Nginx
sudo apt install nginx -y  # Ubuntu/Debian
# sudo yum install nginx -y  # CentOS

# 创建 Nginx 配置
sudo vim /etc/nginx/conf.d/jhchat.conf
```

**Nginx 配置示例：**
```nginx
server {
    listen 80;
    server_name your-domain.com;

    # 前端
    location / {
        proxy_pass http://localhost:5173;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_cache_bypass $http_upgrade;
    }

    # 后端 API
    location /api {
        proxy_pass http://localhost:3001;
        proxy_http_version 1.1;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header Host $http_host;
    }

    # WebSocket 支持
    location /socket.io {
        proxy_pass http://localhost:3001;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header Host $host;
    }
}
```

```bash
# 测试配置并重启 Nginx
sudo nginx -t
sudo systemctl restart nginx
```

#### 配置 HTTPS（使用 Let's Encrypt）

```bash
# 安装 Certbot
sudo apt install certbot python3-certbot-nginx -y

# 获取证书
sudo certbot --nginx -d your-domain.com

# 自动续期（已添加到 cron）
sudo certbot renew --dry-run
```

## 方式二：宝塔 Linux 面板安装

### 第 1 步：安装宝塔面板

```bash
# CentOS 安装脚本
yum install -y wget && wget -O install.sh https://download.bt.cn/install/install_6.0.sh && sh install.sh ed8484bec

# Ubuntu/Debian 安装脚本
wget -O install.sh https://download.bt.cn/install/install_6.0.sh && bash install.sh ed8484bec
```

安装完成后，访问面板地址并登录。

### 第 2 步：安装运行环境

在宝塔面板中安装以下软件：

1. **MySQL 8.0**
   - 进入「软件商店」
   - 搜索"MySQL"
   - 选择 MySQL 8.0 点击安装
   - 设置 root 密码（请妥善保管）

2. **Node.js 20**
   - 进入「软件商店」
   - 搜索"Node.js"
   - 选择 Node.js 20 安装

3. **PM2 进程管理器**
   - 进入「软件商店」
   - 搜索"PM2"
   - 安装 PM2 管理器

4. **Nginx**
   - 进入「软件商店」
   - 安装 Nginx（如未默认安装）

### 第 3 步：创建数据库

```bash
# 登录 MySQL
mysql -u root -p

# 创建数据库和用户
CREATE DATABASE jhchat CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER 'jhchat_user'@'localhost' IDENTIFIED BY 'YourStrongPassword123!';
GRANT ALL PRIVILEGES ON jhchat.* TO 'jhchat_user'@'localhost';
FLUSH PRIVILEGES;
EXIT;
```

### 第 4 步：部署代码

#### 上传代码

1. 进入宝塔面板「文件」
2. 进入网站目录（如：`/www/wwwroot`）
3. 创建目录 `jhchat`
4. 点击「上传」，上传项目代码 ZIP 包
5. 解压 ZIP 包

#### 或通过 Git 克隆

```bash
cd /www/wwwroot/jhchat
git clone <仓库地址> .
```

### 第 5 步：配置后端

```bash
# 进入后端目录
cd /www/wwwroot/jhchat/backend

# 复制环境变量
cp .env.example .env

# 编辑配置
vim .env
```

**修改以下配置：**
```bash
DB_HOST=localhost
DB_PORT=3306
DB_USER=jhchat_user
DB_PASS=YourStrongPassword123!
DB_NAME=jhchat
NODE_ENV=production
PORT=3001
```

#### 安装依赖并初始化数据库

```bash
# 安装依赖
npm install --production

# 初始化数据库表
node src/scripts/init-db.js

# 插入初始数据
node src/scripts/seed.js
```

#### 使用 PM2 启动后端

在宝塔面板中：
1. 进入「PM2 管理器」
2. 点击「添加 Node 项目」
3. 填写配置：
   - 项目目录：`/www/wwwroot/jhchat/backend`
   - 启动文件：`src/server.js`
   - 项目别名：`jhchat-backend`
   - 内存限制：默认
   - 最大重启次数：默认
4. 点击「确定」

或使用命令行：
```bash
pm2 start src/server.js --name jhchat-backend
pm2 save
pm2 startup
```

### 第 6 步：部署前端

```bash
# 进入前端目录
cd /www/wwwroot/jhchat/frontend

# 修改 API 地址（如需要）
# 编辑 vite.config.js 或 .env.production

# 安装依赖
npm install

# 生产构建
npm run build

# 输出目录：dist/
```

#### 配置 Nginx

在宝塔面板中：
1. 进入「网站」→「添加站点」
2. 填写配置：
   - 域名：your-domain.com（或服务器 IP）
   - 根目录：`/www/wwwroot/jhchat/frontend/dist`
   - PHP 版本：纯静态
   - 数据库：无需创建
3. 点击「提交」

#### 配置反向代理

1. 进入网站设置 → 「反向代理」
2. 添加反向代理：
   - 代理名称：`backend-api`
   - 目标 URL：`http://localhost:3001`
   - 发送域名：`$host`
   - 代理目录：`/api`
3. 点击「提交」

#### 配置 WebSocket 支持

在 Nginx 配置中添加（在网站设置 → 「配置文件」中编辑）：

```nginx
location /socket.io {
    proxy_pass http://127.0.0.1:3001;
    proxy_http_version 1.1;
    proxy_set_header Upgrade $http_upgrade;
    proxy_set_header Connection "upgrade";
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
}
```

## 数据库文件说明

项目提供三套 SQL 文件，位于 `database/` 目录：

### 1. 01-schema.sql（基础表结构）

包含 15 张核心表：
- users - 用户表
- system_config - 系统配置
- sects - 门派表
- ip_locks / ip_bans - IP 管理
- operation_logs / kill_logs - 日志表
- chat_rooms / chat_messages / chat_actions - 聊天系统
- online_users / mute_list / fight_bans - 在线用户管理
- messages / news / announcements - 邮件与公告
- items / special_items / alchemy_items - 物品系统
- card_templates / user_cards - 卡片系统
- insurance_products / user_insurances - 保险系统
- martial_arts / secret_skills / learned_skills - 武功系统
- star_pets / mini_pets / sheep_pets / pet_rules - 宠物系统
- bank_accounts - 银行系统

### 2. 02-seed-data.sql（初始数据）

包含基础数据：
- 系统房间（5 个）
- 聊天动作（27 个）
- 门派（8 个）
- 系统配置（27 项）
- 管理员账号（1 个）

### 3. 03-migrations.sql（功能扩展）

包含 15 张新增功能表：
- medical_records - 医疗记录
- loans - 贷款记录
- lovers - 情人关系
- work_records - 工作记录
- admin_silver_logs - 管理员改钱日志
- work_status - 工作状态跟踪
- encounter_records - 奇遇系统
- fishing_records - 钓鱼系统
- fortune_records - 算命系统
- random_events - 随机事件
- meditate_records - 打坐系统
- pet_init_rules - 宠物初始化
- ship_battle_records - 舰船战斗（如适用）
- user_faction_logs - 门派日志（如适用）
- user_stats - 用户统计（如适用）

## 常见问题

### Q1: 数据库连接失败

**问题：** 启动时提示 `ECONNREFUSED` 或 `Access denied`

**解决：**
```bash
# 检查 MySQL 是否运行
docker-compose ps  # Docker 方式
pm2 status  # 宝塔方式

# 验证数据库配置
cat backend/.env
```

### Q2: 前端页面空白

**问题：** 访问前端页面显示空白

**解决：**
1. 检查前端是否已构建
2. 检查 Nginx 配置文件根目录
3. 查看浏览器控制台错误信息
4. 确认 WebSocket 连接正常

### Q3: WebSocket 连接失败

**问题：** 登录后无法发送消息或聊天室不更新

**解决：**
1. 检查后端 PM2 进程是否正常
2. 验证 Nginx 的 WebSocket 配置
3. 检查防火墙是否开放端口
4. 查看后端日志：`pm2 logs jhchat-backend`

### Q4: 管理员无法登录

**问题：** 登录时提示密码错误

**解决：**
```bash
# 重置管理员密码
docker-compose exec backend node src/scripts/seed.js  # Docker 方式
cd backend && node src/scripts/seed.js  # 宝塔方式

# 确认账号信息
mysql -u jhchat_user -p -e "USE jhchat; SELECT username FROM users WHERE grade = 10;"
```

### Q5: 如何备份数据库？

**Docker 方式：**
```bash
# 备份
docker-compose exec db mysqldump -u root -pjhchat_root_pass jhchat > backup.sql

# 恢复
docker-compose exec -T db mysql -u root -pjhchat_root_pass jhchat < backup.sql
```

**宝塔方式：**
```bash
# 使用宝塔面板
# 数据库 → jhchat → 备份

# 或命令行
mysqldump -u jhchat_user -p jhchat > backup.sql
```
