# 门派系统快速使用指南

## 🚀 快速开始

### 1. 创建门派

**条件：**
- ✅ 等级 ≥ 5
- ✅ 100 万两银子
- ✅ 当前无门派

**步骤：**
```
1. 进入门派页面
2. 点击"创建门派"按钮
3. 填写信息：
   - 门派名称 ⭐ （必填，不能用"六扇门"）
   - 门派口号（可选）
   - 门派介绍（可选）
   - 门规（可选）
   - 性别限制（可选）
4. 确认创建 → 自动成为掌门
```

---

### 2. 加入门派

**条件：**
- ✅ 当前无门派
- ✅ 符合性别要求

**步骤：**
```
方式一：主动申请
1. 进入门派页面
2. 浏览门派列表
3. 点击想加入的门派
4. 点击"加入门派"按钮

方式二：被招收
1. 等掌门/长老招收
2. 自动加入成为弟子
```

---

### 3. 掌门管理（核心功能）

#### 👑 禅让掌门

```
1. 进入门派页面
2. 在成员列表中找到想禅让的人
3. 点击"禅让"按钮
4. 确认禅让
→ 您成为长老，对方成为新掌门
```

#### 📢 招收弟子

```
1. 进入门派页面
2. 点击"招收弟子"按钮（掌门管理面板）
3. 输入用户名
4. 确认招收
→ 用户成为普通弟子
```

#### ⚠️ 开除弟子

```
1. 进入门派页面
2. 在成员列表中找到要开除的人
3. 点击"开除"按钮
4. 确认开除
→ 用户被逐出师门
```

#### 💥 解散门派

```
1. 进入门派页面
2. 点击"解散门派"按钮（掌门管理面板）
3. 输入门派名称确认
4. 确认解散
→ 所有成员被除名，门派解散
```

---

### 4. 门派成员

#### 掌门权限
- ✅ 招收弟子
- ✅ 开除弟子
- ✅ 禅让掌门
- ✅ 解散门派
- ✅ 修改门派信息
- ✅ 领取俸禄

#### 长老权限
- ✅ 招收弟子
- ✅ 领取俸禄
- ✅ 离开门派

#### 普通弟子权限
- ✅ 领取俸禄
- ✅ 离开门派

---

### 5. 领取俸禄

**计算公式：**
```
俸禄 = 等级 × 500 两
```

**步骤：**
```
1. 进入门派页面
2. 查看"我的门派信息"
3. 点击"领取俸禄"
→ 银两自动到账
```

**规则：**
- ✅ 每日可领一次（零点刷新）
- ✅ 必须已加入门派
- ✅ 自动判断是否可领

## 🎯 常见问题

### Q1: 如何成为掌门？

**A:** 两种方式：
1. **创建门派** - 自己创建，自动成为掌门
2. **禅让继位** - 其他掌门禅让给您

### Q2: 如何离开门派？

**A:** 
```
1. 进入门派页面
2. 点击"离开门派"按钮
3. 确认离开
→ 扣除 5 万两 + 500 内力，成为无门派
```

### Q3: 创建门派要多少钱？

**A:** 100 万两银子（创建时自动扣除）

### Q4: 可以创建几个门派？

**A:** 一个用户同时只能有一个门派
- 要创建新门派，需先离开当前门派
- 六扇门是朝廷机构，不可创建

### Q5: 如何招收更多弟子？

**A:** 
- 掌门和长老都可以招收
- 只能招收无门派的玩家
- 必须符合门派性别限制
- 没有人数上限

### Q6: 门派可以解散吗？

**A:** 可以，掌门有权解散：
```
1. 点击"解散门派"
2. 输入门派名称确认
3. 所有成员自动除名
```

注意：
- 六扇门不可解散
- 解散需谨慎，不可恢复

### Q7: 禅让后我是什么身份？

**A:** 禅让后自动成为**长老**

### Q8: 被开除了会怎样？

**A:** 
- 自动成为无门派人士
- 可以重新加入其他门派
- 不影响其他属性

## 📊 门派等级

```
掌门  → 创建者或禅让继位，拥有全部权限
  ↓
长老  → 禅让后的掌门，可以招收弟子
  ↓
普通弟子 → 普通成员，基础权限
```
