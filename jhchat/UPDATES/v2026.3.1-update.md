## 数据库变更

### 新增字段
```sql
-- 用户表新增字段
ALTER TABLE users ADD COLUMN `chat_minutes_today` INT UNSIGNED DEFAULT 0;
ALTER TABLE users ADD COLUMN `chat_minutes_total` INT UNSIGNED DEFAULT 0;
ALTER TABLE users ADD COLUMN `last_chat_time` DATETIME DEFAULT NULL;

-- 字段重命名（兼容旧数据）
ALTER TABLE users CHANGE COLUMN `all_value` `total_exp` BIGINT NOT NULL DEFAULT 0;
ALTER TABLE users CHANGE COLUMN `month_value` `monthly_exp` BIGINT NOT NULL DEFAULT 0;
```

## 安装步骤

### 方式一：一键 Git 同步（推荐）
```bash
cd /www/wwwroot/jhchat
git pull origin 260413-feat-jhchat-refactor
```

### 方式二：手动更新
1. 备份当前代码和数据
2. 拉取新代码
3. 执行数据库同步脚本
4. 重启服务

### 数据库同步
```bash
# 执行增量同步脚本
mysql -u jhchat -p jhchat < database/production-sync-v2026.3.sql

# 或手动执行字段变更
ALTER TABLE users CHANGE COLUMN `all_value` `total_exp` BIGINT NOT NULL DEFAULT 0;
ALTER TABLE users CHANGE COLUMN `month_value` `monthly_exp` BIGINT NOT NULL DEFAULT 0;
```

### 重启服务
```bash
# 后端
pm2 restart jhchat-backend

# 前端（如果需要重新构建）
cd /www/wwwroot/jhchat/frontend
npm run build
pm2 restart jhchat-frontend
```
