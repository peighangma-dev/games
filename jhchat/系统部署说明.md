# 笑傲江湖聊天室 - 系统部署说明

## 部署环境要求

### 服务器配置
- **CPU**: 2 核心以上
- **内存**: 4GB 以上（推荐 8GB）
- **磁盘**: 20GB 可用空间
- **网络**: 公网 IP，开放端口 80/443

### 软件要求
- Node.js 20.x 或更高版本
- MySQL 8.0 或更高版本
- Redis 7.0 或更高版本
- Git

---

## 部署方式一：Docker 部署（推荐）

### 1. 安装 Docker
```bash
# Ubuntu/Debian
sudo apt-get update
sudo apt-get install docker.io docker-compose-plugin

# CentOS/RHEL
sudo yum install docker docker-compose
```

### 2. 克隆项目
```bash
cd /var/www
git clone <项目地址> jhchat
cd jhchat
```

### 3. 配置文件
```bash
# 后端环境变量
cd backend
cp .env.example .env
# 编辑 .env，修改数据库密码等配置
```

### 4. 启动服务
```bash
# 启动所有容器
docker-compose up -d

# 查看运行状态
docker-compose ps

# 查看日志
docker-compose logs -f backend
```

### 5. 初始化数据库
```bash
# 等待 MySQL 启动完成（约 30 秒）
docker-compose exec backend node src/scripts/init-db.js

# 插入种子数据
docker-compose exec backend node src/scripts/seed.js
```

### 6. 验证部署
访问 http://服务器IP:5173 或使用 Nginx 反向代理

## 部署方式二：手动部署

### 1. 安装依赖
```bash
# 安装 Node.js 环境
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt-get install -y nodejs

# 安装全局工具
npm install -g pm2
```

### 2. 后端部署
```bash
cd jhchat/backend

# 安装依赖
npm install

# 配置环境变量
cp .env.example .env
# 编辑 .env 配置数据库连接

# 初始化数据库
npm run init-db
npm run seed

# 启动服务（开发环境）
npm run dev

# 启动服务（生产环境，使用 PM2）
pm2 start src/server.js --name jhchat-backend
```

### 3. 前端部署
```bash
cd jhchat/frontend

# 安装依赖
npm install

# 构建生产版本
npm run build

# 设置 Nginx 反向代理指向 dist/ 目录
```

### 4. Nginx 配置
```nginx
server {
    listen 80;
    server_name your-domain.com;
    root /var/www/jhchat/frontend/dist;
    index index.html;

    # 前端静态文件
    location / {
        try_files $uri $uri/ /index.html;
    }

    # 后端 API 代理
    location /api {
        proxy_pass http://localhost:3001;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_cache_bypass $http_upgrade;
    }

    # Socket.IO
    location /socket.io {
        proxy_pass http://localhost:3001;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header Host $host;
        proxy_cache_bypass $http_upgrade;
    }

    # 上传文件
    location /uploads {
        proxy_pass http://localhost:3001;
    }

    # 静态资源
    location /assets {
        proxy_pass http://localhost:3001;
    }
}
```

### 5. 启动服务
```bash
# 重启 Nginx
sudo systemctl restart nginx

# 使用 PM2 管理后端
pm2 start backend/src/server.js --name jhchat-api
pm2 save
pm2 startup
```

## 数据库配置

### MySQL 配置
```sql
-- 创建数据库
CREATE DATABASE jhchat CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

-- 创建用户（可选）
CREATE USER 'jhchat_user'@'localhost' IDENTIFIED BY 'strong_password';
GRANT ALL PRIVILEGES ON jhchat.* TO 'jhchat_user'@'localhost';
FLUSH PRIVILEGES;
```

### Redis 配置
```bash
# 编辑 Redis 配置
sudo nano /etc/redis/redis.conf

# 设置密码
requirepass your_redis_password

# 重启 Redis
sudo systemctl restart redis
```

## 生产环境优化

### 1. 性能优化
- 启用 Gzip 压缩
- 配置浏览器缓存
- 使用 CDN 加速静态资源
- 数据库查询优化（索引）

### 2. 安全加固
- 配置 HTTPS（Let's Encrypt）
- 设置防火墙规则
- 启用 fail2ban 防护
- 定期备份数据库

### 3. 监控日志
```bash
# 安装 PM2 监控
pm2 install pm2-logrotate

# 查看后端日志
pm2 logs jhchat-api

# 查看 Nginx 访问日志
tail -f /var/log/nginx/access.log
```

## 常见问题排查

### 1. 后端无法启动
```bash
# 检查端口占用
netstat -tlnp | grep 3001

# 查看 PM2 日志
pm2 logs jhchat-api --lines 50

# 检查数据库连接
mysql -u jhchat_user -p -e "SELECT 1"
```

### 2. 前端页面空白
- 检查 Nginx 配置
- 查看浏览器控制台错误
- 确认 API 代理正常

### 3. Socket.IO 连接失败
- 确认 WebSocket 代理配置正确
- 检查防火墙是否开放端口
- 查看后端 Socket 事件日志

## 备份与恢复

### 数据库备份
```bash
# 备份数据库
mysqldump -u jhchat_user -p jhchat > backup_$(date +%Y%m%d).sql

# 恢复数据库
mysql -u jhchat_user -p jhchat < backup_20260421.sql
```

### 文件备份
```bash
# 备份上传文件
tar -czf uploads_backup.tar.gz backend/uploads/

# 恢复上传文件
tar -xzf uploads_backup.tar.gz -C /var/www/jhchat/
```

## 升级指南

### 版本升级步骤
1. 备份数据库和文件
2. 拉取最新代码
3. 安装新依赖 `npm install`
4. 执行数据库迁移（如有）
5. 重启服务

```bash
# 更新代码
cd /var/www/jhchat
git pull

# 更新依赖
cd backend && npm install
cd ../frontend && npm install

# 重新构建前端
npm run build

# 重启后端
pm2 restart jhchat-api
```
