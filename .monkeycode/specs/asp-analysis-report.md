## 一、系统概述

"笑傲江湖XP"是一个武侠主题聊天室系统，以实时聊天为核心，围绕武侠世界观构建了完整的虚拟社区生态。系统包含约369个ASP文件、40+张数据表、1056+个图片资源，涵盖用户管理、实时聊天、门派系统、经济系统、婚姻系统、宠物系统、工作系统、游戏系统等十余个子系统。

**核心技术架构：**
- 服务端：ASP (VBScript)，运行于 IIS
- 数据库：Microsoft Access Jet 4（主库文件伪装为 `global.asp`，密码 `cklovesnow`）
- 辅助数据库：`xajhxp/pic.asp`（相册系统）、`jhqc/shuxi.mdb`（藏经阁）、`jhqy/db.mdb`（许愿墙）、`myhome/setup.mdb`（宠物）、`yhy/yhy.mdb`（烟花院）
- 前端：HTML + JavaScript + Java Applet (AnLake水面特效)
- 实时通信：Application级变量 + 客户端定时刷新（非WebSocket）

**数据库连接方式**（`Global.asa`）：
```vbscript
connstr="Provider=Microsoft.Jet.OLEDB.4.0;Data Source="& Server.MapPath("global.asp") & ";jet oledb:database password=cklovesnow"
Application("fdlm_c_connstr")=connstr
Application("fdlm_wen")="DBQ="+server.mappath("xajhxp/pic.asp")+";DefaultDir=;DRIVER={Microsoft Access Driver (*.mdb)};"
```

**密码加密算法**（`joinjhnow.asp`）：
```vbscript
temppass=StrReverse(left(psw&"qazwsxe,./",10))
templen=len(psw)
mmpassword=""
for j=1 to 10
    mmpassword=mmpassword+chr(asc(mid(temppass,j,1))-templen+int(j*1.1))
next
psw=replace(mmpassword,"'","B")
```

- **写入**：整体前移9位 -> 新消息写入末尾9位 -> 更新Application

| 数据库伪装 | global.asp实为MDB文件 | Global.asa |
| 发言限速 | 3秒间隔 | SAY.ASP |
| 脏词过滤 | 客户端+服务端双重过滤 | Jhchat.asp + SAY.ASP |

## 七、系统架构总结

### 7.1 核心架构特征

1. **数据库**：Microsoft Access (Jet 4)，单文件，伪装为ASP
2. **会话管理**：ASP Session + Application变量
3. **实时通信**：客户端定时刷新(非WebSocket)，Application级消息队列
4. **在线管理**：Application级数组，每用户6字段
5. **消息推送**：循环缓冲区(20条/房间)，客户端记录行号增量获取
